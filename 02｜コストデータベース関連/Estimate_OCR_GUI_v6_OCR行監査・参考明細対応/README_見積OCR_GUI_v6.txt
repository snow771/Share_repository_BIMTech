協力業者見積 AI-OCR GUI v6（OCR行監査対応）

【v6の重要な改修】
OCRで取得した名称付き行を、単価・金額がなくても「参考明細」として最終出力へ残します。
金額がある行は「金額明細」、参考・数量・注記系の行は「参考明細」です。

【確認方法】
最終Excelには次の3シートがあります。
- 構造化明細：金額明細と参考明細を含む最終結果
- 集計・確認：金額集計。参考明細は金額合計から除外
- OCR行監査：OCR表の各行を「採用／見出し／除外」で一覧化。除外理由も確認可能

【起動】
Launch_Estimate_OCR_GUI_v6.bat をダブルクリック

【必要ファイル】
このZIP内のファイルはすべて同じフォルダに置いてください。

【初回のみ】
python -m pip install azure-ai-documentintelligence==1.0.2 openpyxl pypdf
